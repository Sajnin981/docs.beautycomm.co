# BeautyComm Help Center

A documentation site for BeautyComm customer support, admin workflows, and product guidance.

## Overview

This project provides a polished, MDX-powered help center built with Next.js and Tailwind. It is designed for:
- customer self-service
- admin and operations guidance
- mobile app support
- troubleshooting and escalation

## Local development

```bash
pnpm install
pnpm generate-content-json
pnpm run dev
```

Then open http://localhost:3000

## Production build

```bash
pnpm run build
pnpm run start
```

## Notes

This help center intentionally avoids unsupported product claims. Content is structured around verified workflow categories and clearly labeled support guidance.
