Create promotions that bring customers back. To create a coupon:

1. Go to **Marketing > Coupons** and click **Add Coupon**.

   <Screenshot alt="BeautyComm Admin Panel Coupons &amp; Discounts screenshot" label="Capture for Coupons &amp; Discounts" description="Capture: Coupons list with the Add button. Suggested filename: admin/coupons/01-list.png" caption="admin/coupons/01-list.png" />

2. Enter the code, and choose the type: percentage or fixed amount.
3. Set the minimum spend, maximum discount, usage limit and start and end dates.

   <Screenshot alt="BeautyComm Admin Panel Coupons &amp; Discounts screenshot" label="Capture for Coupons &amp; Discounts" description="Capture: Coupon form with limits and dates. Suggested filename: admin/coupons/02-form.png" caption="admin/coupons/02-form.png" />

4. Choose what it applies to: all products, certain categories or certain customers.
5. Click **Save**. Turn it on or off any time from the list.

Check a new coupon on the storefront before announcing it.
