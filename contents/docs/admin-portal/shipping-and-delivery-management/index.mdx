## Shipping

The Shipping menu contains: **Shipping Countries** and **Shipping City**.

- **Shipping City** shows Total Cities, Cities with Shipping Cost and Free Shipping Cities.
- Each row has an ID, City Name, Shipping Cost (৳) and an edit action. Use **Add New City** to add a city.
- Set a city’s cost to 0 for free shipping.
- **Shipping Countries** lists the countries you deliver to, and you can add or edit them the same way.
