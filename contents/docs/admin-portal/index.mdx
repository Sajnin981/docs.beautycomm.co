The Admin Panel documentation is for authorized business staff responsible for operating a BeautyComm-powered store. The guides cover catalogue management, orders, configuration, reporting, and other store operations.

Start with [Dashboard & Best Practices](/docs/admin-portal/dashboard-and-best-practices) for operational guidance.
For personal shopping activity, use the [User Portal](/docs/user-portal).
