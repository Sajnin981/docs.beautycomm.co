The Admin Panel documentation is for authorized business staff responsible for operating a BeautyComm-powered store. The guides below organize proposed admin topics, from catalogue and orders to configuration and reporting.

Start with [Dashboard & Best Practices](/docs/admin-portal/dashboard-and-best-practices) for operational guidance. Available modules and actions depend on the product release and each staff member’s access.

The workflows in these guides are based on the supplied operational guides. Confirm menu names and actions against the live Admin Panel and staff role before use. Screenshot blocks are placeholders; capture them at a consistent desktop size with demo data, and obscure customer details, API keys, and other secrets.

For personal shopping activity, use the [User Portal](/docs/user-portal). For the public shopping experience, see the [Storefront](/docs/storefront).
