Define the skin types and concerns used in recommendations. To manage them:

1. Go to **Skin Types** and click **Add Skin Type**.

2. Enter the name and description. Add values such as Oily, Dry or Sensitive.
3. Go to **Preferences** to manage concerns such as acne, dullness or pigmentation.

4. Tag products with the skin types and concerns they suit.
