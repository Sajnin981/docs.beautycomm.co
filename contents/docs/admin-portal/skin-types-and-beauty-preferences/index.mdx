Define the skin types and concerns used in recommendations. To manage them:

1. Go to **Skin Types** and click **Add Skin Type**.

   <Screenshot alt="BeautyComm Admin Panel Skin Types &amp; Beauty Preferences screenshot" label="Capture for Skin Types &amp; Beauty Preferences" description="Capture: Skin types list. Suggested filename: admin/skin-types/01-list.png" caption="admin/skin-types/01-list.png" />

2. Enter the name and description. Add values such as Oily, Dry or Sensitive.
3. Go to **Preferences** to manage concerns such as acne, dullness or pigmentation.

   <Screenshot alt="BeautyComm Admin Panel Skin Types &amp; Beauty Preferences screenshot" label="Capture for Skin Types &amp; Beauty Preferences" description="Capture: Concerns and preferences list. Suggested filename: admin/skin-types/02-preferences.png" caption="admin/skin-types/02-preferences.png" />

4. Tag products with the skin types and concerns they suit.

   <Screenshot alt="BeautyComm Admin Panel Skin Types &amp; Beauty Preferences screenshot" label="Capture for Skin Types &amp; Beauty Preferences" description="Capture: Product form with skin type tags. Suggested filename: admin/skin-types/03-product-tags.png" caption="admin/skin-types/03-product-tags.png" />
