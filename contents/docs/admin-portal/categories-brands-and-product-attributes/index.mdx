## Brand

The Brand menu contains: **Add Brand**, **Brands** and **Verify Brands**.

1. Open Brand > Add Brand.
2. Enter Brand Name and Slug (both required), then Meta Title and Brand Category.
3. Upload a Logo (max 2 MB) and switch **Is Top Brand** on if the brand should be featured.
4. Add a Meta Description and save.

![Add New Brand page](/images/admin/ss05-add-new-brand.png)

The **Brands** list shows ID, Name, Slug, Category, Is Top and Is Active, with edit and delete actions. **Verify Brands** lists brands waiting for approval before they appear on the storefront.

## Category

The Category menu contains: **Add Category** and **Categories**.

1. Open Category > Add Category.
2. Choose **Parent Categories** if this is a sub-category.
3. Enter Name, Slug, Order Level and Shipping Cost, then Meta Title and Meta Description.
4. Save.

The **Categories** list has tabs for All, Active and Inactive. Each row has switches for **is Top**, **is Coupon Applicable**, **is Budget Friendly**, **Is By Brands** and **Active**, plus edit and delete actions.
