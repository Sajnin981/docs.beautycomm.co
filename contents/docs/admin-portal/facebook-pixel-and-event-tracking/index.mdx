Track visitor actions to improve your Facebook and Instagram ads. To connect it:

1. Go to **Marketing > Facebook Pixel**.

   <Screenshot alt="BeautyComm Admin Panel Facebook Pixel &amp; Event Tracking screenshot" label="Capture for Facebook Pixel &amp; Event Tracking" description="Capture: Facebook Pixel settings. Suggested filename: admin/pixel/01-settings.png" caption="admin/pixel/01-settings.png" />

2. Paste your **Pixel ID** from Facebook Events Manager [blur the ID].
3. Choose which events to track, such as Page View, Add to Cart, Checkout and Purchase.

   <Screenshot alt="BeautyComm Admin Panel Facebook Pixel &amp; Event Tracking screenshot" label="Capture for Facebook Pixel &amp; Event Tracking" description="Capture: Event tracking checklist. Suggested filename: admin/pixel/02-events.png" caption="admin/pixel/02-events.png" />

4. Save, then test it with Facebook's **Pixel Helper** tool or Events Manager test events.

   <Screenshot alt="BeautyComm Admin Panel Facebook Pixel &amp; Event Tracking screenshot" label="Capture for Facebook Pixel &amp; Event Tracking" description="Capture: Test events result in Events Manager. Suggested filename: admin/pixel/03-test.png" caption="admin/pixel/03-test.png" />

Follow the privacy and cookie rules that apply in your region.
