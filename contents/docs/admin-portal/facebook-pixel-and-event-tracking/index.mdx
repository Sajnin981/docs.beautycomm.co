Track visitor actions to improve your Facebook and Instagram ads. To connect it:

1. Go to **Marketing > Facebook Pixel**.

2. Paste your **Pixel ID** from Facebook Events Manager [blur the ID].
3. Choose which events to track, such as Page View, Add to Cart, Checkout and Purchase.

4. Save, then test it with Facebook's **Pixel Helper** tool or Events Manager test events.

Follow the privacy and cookie rules that apply in your region.
