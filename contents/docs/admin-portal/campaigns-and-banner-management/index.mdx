## Coupons

Create discount codes that customers enter in the Coupon field at checkout.

1. Open **Promotions > Coupons**, then select **Add Coupon**.
2. Enter a code and choose a fixed amount or percentage discount.
3. Set the start and end dates, minimum order amount and usage limit.
4. Save the coupon, then try it on a test order to confirm the Discount line changes.

## Flash Sales

Run short, time-limited offers to create urgency, including group-buying deals.

- Select the products and set the sale price.
- Choose the start and end time, and the quantity available at that price.
- Publish the sale and check that its countdown and price appear on the storefront.
- When the sale ends, confirm the products return to their normal price and availability.

## Banners & Campaigns

Banners are large images on the Home page, and campaigns group them with the offers they promote.

1. Upload the banner image in the recommended size.
2. Add a link so a click opens a product, category or offer page.
3. Set the schedule and the order in which banners appear.
4. Preview the Home page before the campaign goes live.

## Notifications

Send email and push messages to keep customers informed and bring them back to the store.

- Write a title and message, and add an image or link if useful.
- Choose who receives it: everyone, a segment or a single customer.
- Send now, or schedule it for a better time.
- Review delivery results to see what worked.

## Subscribers

This page lists the people who signed up for marketing messages.

1. Open Subscribers to see names, email addresses and sign-up dates.
2. Search or filter to find a particular person.
3. Export the list when needed for a campaign.
4. Remove anyone who asks to unsubscribe.

## Facebook Pixel

The Facebook Pixel measures what customers do after clicking your ads.

- Paste your Pixel ID into the field provided.
- Choose the events to track, such as page views, add to cart and purchase.
- Save, then use Facebook's testing tool to confirm events arrive.

## Tag Manager

Google Tag Manager connects the store to analytics and advertising tags without editing application code.

1. Copy your container ID from Google Tag Manager.
2. Paste it into the Tag Manager field and save.
3. Open the store in Tag Manager preview mode to confirm the container loads.
4. Publish tags only after they fire correctly.
