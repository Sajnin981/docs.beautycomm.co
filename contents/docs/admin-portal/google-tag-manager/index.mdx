Manage tracking tags without changing store code. To connect it:

1. Go to **Marketing > Google Tag Manager**.

   <Screenshot alt="BeautyComm Admin Panel Google Tag Manager screenshot" label="Capture for Google Tag Manager" description="Capture: GTM settings. Suggested filename: admin/gtm/01-settings.png" caption="admin/gtm/01-settings.png" />

2. Enter your **Container ID** (it starts with GTM-) [blur the ID].
3. Save, then use **Preview** mode in Tag Manager to confirm tags fire correctly.

   <Screenshot alt="BeautyComm Admin Panel Google Tag Manager screenshot" label="Capture for Google Tag Manager" description="Capture: Tag Manager preview mode. Suggested filename: admin/gtm/02-preview.png" caption="admin/gtm/02-preview.png" />

4. Publish your container in Tag Manager when ready.
