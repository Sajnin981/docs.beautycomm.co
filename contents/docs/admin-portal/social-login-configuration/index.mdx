Let customers log in with their social accounts. To set it up:

1. Go to **Settings > Social Login**.

   <Screenshot alt="BeautyComm Admin Panel Social Login Configuration screenshot" label="Capture for Social Login Configuration" description="Capture: Social login settings. Suggested filename: admin/social-login/01-settings.png" caption="admin/social-login/01-settings.png" />

2. Choose a provider such as Google or Facebook.
3. Create an app in the provider's developer console and copy its **Client ID** and **Client Secret** [blur both].

   <Screenshot alt="BeautyComm Admin Panel Social Login Configuration screenshot" label="Capture for Social Login Configuration" description="Capture: Provider credential form. Suggested filename: admin/social-login/02-credentials.png" caption="admin/social-login/02-credentials.png" />

4. Add the callback URL shown on the page to the provider's app settings.
5. Enable the provider and save, then test by logging in on the storefront.
