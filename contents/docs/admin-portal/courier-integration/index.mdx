Connect a courier so orders can be booked and tracked automatically. To connect:

1. Go to **Settings > Couriers** and choose your courier.

   <Screenshot alt="BeautyComm Admin Panel Courier Integration screenshot" label="Capture for Courier Integration" description="Capture: Courier list. Suggested filename: admin/courier/01-list.png" caption="admin/courier/01-list.png" />

2. Enter the required details, such as API key or store ID [from your courier account].

   <Screenshot alt="BeautyComm Admin Panel Courier Integration screenshot" label="Capture for Courier Integration" description="Capture: Courier connection form (blur keys). Suggested filename: admin/courier/02-form.png" caption="admin/courier/02-form.png" />

3. Click **Save** and run **Test Connection**.
4. When creating a shipment, choose the courier to book it and get a tracking number.

Never share API keys in screenshots or messages.
