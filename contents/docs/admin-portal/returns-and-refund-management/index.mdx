Review and resolve return requests. To process a request:

1. Go to **Returns**.

   <Screenshot alt="BeautyComm Admin Panel Returns &amp; Refund Management screenshot" label="Capture for Returns &amp; Refund Management" description="Capture: Returns list. Suggested filename: admin/returns/01-list.png" caption="admin/returns/01-list.png" />

2. Click a request to see the items, reason and photos.

   <Screenshot alt="BeautyComm Admin Panel Returns &amp; Refund Management screenshot" label="Capture for Returns &amp; Refund Management" description="Capture: Return request details. Suggested filename: admin/returns/02-details.png" caption="admin/returns/02-details.png" />

3. Click **Approve** or **Reject**, and add a note for the customer.
4. When the item arrives, inspect it and mark it as **Received**.
5. Click **Refund** and choose the refund method.

   <Screenshot alt="BeautyComm Admin Panel Returns &amp; Refund Management screenshot" label="Capture for Returns &amp; Refund Management" description="Capture: Refund dialog. Suggested filename: admin/returns/03-refund.png" caption="admin/returns/03-refund.png" />

6. Restock the item if it can be sold again.

Follow your published Returns & Refund Policy so decisions stay fair and consistent.
