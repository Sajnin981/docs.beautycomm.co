## Content & Engagement

### Uploaded Files

This is the library of every image and file uploaded across the panel, such as product thumbnails and large images. Files appear as tiles showing a preview, the file name, size, type (JPG, JFIF) and upload date.

1. Open **Content & Engagement** in the left sidebar and select **Uploaded Files**.
2. Select **Upload New File** to add an image or file.
3. Use the **Newest** menu to change the order, or type in the search box and select **Filter** to find a file by name. **Clear** resets the list.
4. Tick the box on a tile to select it. The counter above the grid shows how many files are selected.
5. Use the three-dot menu on a tile to work with that file, for example to copy its link or delete it.
6. Before deleting a file, check that no product or banner still uses it.
