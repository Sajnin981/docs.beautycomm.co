Let customers order products before they arrive. To set up a preorder:

1. Open the product and turn on **Preorder**.

   <Screenshot alt="BeautyComm Admin Panel Preorders screenshot" label="Capture for Preorders" description="Capture: Preorder toggle on the product page. Suggested filename: admin/preorders/01-toggle.png" caption="admin/preorders/01-toggle.png" />

2. Set the expected availability date and any limit on quantity.
3. Customers now see **Preorder** on the product page. Manage them under **Preorders**.

   <Screenshot alt="BeautyComm Admin Panel Preorders screenshot" label="Capture for Preorders" description="Capture: Preorders list. Suggested filename: admin/preorders/02-list.png" caption="admin/preorders/02-list.png" />

4. When stock arrives, convert the preorders to normal orders and ship them.

Show an honest availability date, so customers know what to expect.
