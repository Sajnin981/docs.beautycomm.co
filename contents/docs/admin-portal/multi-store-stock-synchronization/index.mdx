If you sell from more than one store or warehouse, keep stock in sync. To set it up:

1. Go to **Stores / Warehouses** and add each location.

   <Screenshot alt="BeautyComm Admin Panel Multi-Store Stock Synchronization screenshot" label="Capture for Multi-Store Stock Synchronization" description="Capture: Stores list. Suggested filename: admin/multistore/01-stores.png" caption="admin/multistore/01-stores.png" />

2. Open **Stock Sync** and choose how stock is shared between locations.

   <Screenshot alt="BeautyComm Admin Panel Multi-Store Stock Synchronization screenshot" label="Capture for Multi-Store Stock Synchronization" description="Capture: Stock sync settings. Suggested filename: admin/multistore/02-sync-settings.png" caption="admin/multistore/02-sync-settings.png" />

3. Check each product's stock per location.

   <Screenshot alt="BeautyComm Admin Panel Multi-Store Stock Synchronization screenshot" label="Capture for Multi-Store Stock Synchronization" description="Capture: Product stock by location. Suggested filename: admin/multistore/03-stock-by-location.png" caption="admin/multistore/03-stock-by-location.png" />

4. Move stock between locations with **Transfer Stock**.

Check sync results after any large change.
