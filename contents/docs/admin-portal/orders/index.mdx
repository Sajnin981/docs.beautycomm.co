Process customer orders from one place. To manage an order:

1. Go to **Orders**. New orders appear at the top.

2. Use the status tabs or filters to find orders by status, date or customer.
3. Click an order to see its items, customer, address, payment and history.

   <Screenshot alt="BeautyComm Admin Panel Orders screenshot" label="Capture for Orders" description="Capture: Order details page. Suggested filename: admin/orders/02-details.png" caption="admin/orders/02-details.png" />

4. Update the status as you go, for example Confirmed, Packed, Shipped, Delivered.

5. Print the invoice or packing slip, or cancel the order if needed.

The customer receives a notification when the status changes.
