Set up the ways customers can pay. To configure a gateway:

1. Go to **Settings > Payment Gateways**.

   <Screenshot alt="BeautyComm Admin Panel Payment Gateway Configuration screenshot" label="Capture for Payment Gateway Configuration" description="Capture: Payment gateways list. Suggested filename: admin/payments/01-list.png" caption="admin/payments/01-list.png" />

2. Choose a gateway, for example [card gateway, mobile banking, cash on delivery].
3. Enter the credentials from your payment provider, such as Store ID and API keys [blur everything].

   <Screenshot alt="BeautyComm Admin Panel Payment Gateway Configuration screenshot" label="Capture for Payment Gateway Configuration" description="Capture: Gateway credentials form. Suggested filename: admin/payments/02-form.png" caption="admin/payments/02-form.png" />

4. Choose **Sandbox / Test** mode first and place a test order.
5. When it works, switch to **Live**, enable the gateway and save.

Never share your live keys with anyone, including in screenshots.
