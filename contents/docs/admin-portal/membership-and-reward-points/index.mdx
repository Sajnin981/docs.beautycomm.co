## Memberships

The Memberships menu contains: **All Membership** and **Add New Membership**.

Memberships are the loyalty levels customers can belong to. Each level can give extra reward points and special shipping terms.

### Add a membership

1. Open Memberships > Add New Membership.
2. Select **Choose Icon** to add a badge image for the level.
3. Enter a **Title** (required) and a **Description** (required).
4. Set the reward rules:
   - **Min Reward Point**: the points a customer needs to reach this level.
   - **Point Percent**: the share of points this level earns on purchases.
   - **Shipping Cost**: the delivery charge for members of this level.
5. Switch **Shipping Cost Applicable** on if the shipping rule should apply. When it is on, enter **Min Amount For Shipping Cost**, the order amount that triggers it.
6. Switch **Hidden** on to keep the level off the storefront.
7. Select **Save Membership**. **Clear Form** empties every field, and **Cancel** leaves without saving.

![Add New Membership page](/images/admin/ss13-add-new-membership.png)

**All Membership** lists every level you have created, where you can edit or remove one.
