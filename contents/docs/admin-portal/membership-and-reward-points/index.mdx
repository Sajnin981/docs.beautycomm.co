Reward loyal customers. To set it up:

1. Go to **Membership**.

2. Create levels such as Silver or Gold, with the spend needed and benefits.
3. Set the points rules: points earned per purchase and the value of each point.

   <Screenshot alt="BeautyComm Admin Panel Membership &amp; Reward Points screenshot" label="Capture for Membership &amp; Reward Points" description="Capture: Points rules form. Suggested filename: admin/membership/02-points-rules.png" caption="admin/membership/02-points-rules.png" />

4. To adjust a customer's points manually, open the customer and use **Adjust Points** with a reason.
