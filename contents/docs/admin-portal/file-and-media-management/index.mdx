Manage the images and files used in your store. To use it:

1. Go to **Media**.

   <Screenshot alt="BeautyComm Admin Panel File &amp; Media Management screenshot" label="Capture for File &amp; Media Management" description="Capture: Media library. Suggested filename: admin/media/01-library.png" caption="admin/media/01-library.png" />

2. Click **Upload** and choose files, or drag them in.
3. Click a file to see its details, copy its link, rename it or delete it.

4. Use the search and folders to find files.

Use compressed images, so pages load fast. Check that a file is not used before deleting it.
