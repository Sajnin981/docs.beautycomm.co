Handle consultation bookings. To manage them:

1. Go to **Consultations**.

   <Screenshot alt="BeautyComm Admin Panel Beauty Consultation Management screenshot" label="Capture for Beauty Consultation Management" description="Capture: Consultation requests list. Suggested filename: admin/consultation/01-list.png" caption="admin/consultation/01-list.png" />

2. Open a request to see the customer's topic and message.
3. Assign it to a consultant, set the time and click **Confirm**.

   <Screenshot alt="BeautyComm Admin Panel Beauty Consultation Management screenshot" label="Capture for Beauty Consultation Management" description="Capture: Assign and confirm form. Suggested filename: admin/consultation/02-assign.png" caption="admin/consultation/02-assign.png" />

4. Mark it **Completed** after the session, and add notes.
