See who did what in the admin panel. To review activity:

1. Go to **Activity Logs**.

   <Screenshot alt="BeautyComm Admin Panel Activity Logs screenshot" label="Capture for Activity Logs" description="Capture: Activity log list. Suggested filename: admin/logs/01-list.png" caption="admin/logs/01-list.png" />

2. Filter by staff member, action type or date.
3. Open an entry to see what changed and when.

   <Screenshot alt="BeautyComm Admin Panel Activity Logs screenshot" label="Capture for Activity Logs" description="Capture: Log entry details. Suggested filename: admin/logs/02-details.png" caption="admin/logs/02-details.png" />

Review logs when something unexpected changes, such as prices or permissions.
