Documentation feedback helps improve clarity, accuracy, and usefulness for all users. If a page is confusing, missing helpful steps, or no longer reflects the live product, share the details so the guidance can be improved.

## What to include

When sending feedback, include:

- the page or section name
- what you expected to find
- what was confusing, missing, or inaccurate
- your role or business context when relevant
- any screenshot, example, or link that helps explain the issue

## Good example feedback

- “This setup guide skips the first essential steps for a new account.”
- “The instructions on this page do not match the current screen layout I see in the product.”
- “This FAQ would be more useful if it included the most common order-status examples.”

## Send it through the correct channel

Use the documentation feedback flow or support channel assigned to your business. If the issue reflects a live product problem, use the support route rather than only documenting the issue in the docs.
