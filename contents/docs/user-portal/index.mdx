This section is for **shoppers** using an online store powered by BeautyComm. It explains how to browse products, place an order, and manage a customer account. If you work for a business that uses BeautyComm to run its store, go to the [Business Admin Panel](/docs/admin-panel) instead.

## Who Should Use This Section

Use these guides if you are buying from a store’s website or mobile shopping experience. You do not need a BeautyComm staff or business-admin account to follow the shopper instructions.

The store controls its own products, prices, delivery areas, payment methods, promotions, and return policies. Those options may differ from one BeautyComm-powered store to another.

## Choose the Right Guide

Start with [Shop and Place an Order](/docs/user-portal/storefront-and-shopping) if you are browsing or checking out. Choose [Manage Your Customer Account](/docs/user-portal/customer-account) to check an existing order, update your profile, use a wishlist or rewards, or get help. If you operate the store, use the [Business Admin Panel](/docs/admin-panel).
