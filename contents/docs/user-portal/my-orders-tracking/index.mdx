## My Orders

My Orders lists every purchase you have made, so you never have to dig through messages to find one.

- Select **My Orders** in the Dashboard sidebar to see orders newest first.
- Each entry shows the order number, date, total and current status.
- Select an order to see its items, delivery address and payment method.

## Tracking

Tracking tells you where your parcel is between placing the order and receiving it.

1. Open **My Orders** and select the order you are waiting for.
2. Select **Track Order** to see its progress.
3. Follow the status steps, for example placed, confirmed, shipped and delivered.
4. If the courier shares a tracking number, use it on the courier's own page for live location.
5. Contact Support if the status has not moved for longer than the estimated delivery time.

## Invoices

Invoices and receipts are your proof of purchase for warranty, returns or personal records.

- Open an order from **My Orders** and select **Invoice**.
- Check the items, prices, shipping, discount and total printed on it.
- Download or print it from the same screen.
- Invoices become available once the order is confirmed.

## Returns

If a product arrives damaged, wrong or unsuitable, you can ask for a return or refund from your account.

1. Open the order from **My Orders** and select **Return**.
2. Choose the item and the reason for the return.
3. Add a short description and a photo if it helps show the problem.
4. Submit the request and note the reference shown.
5. Follow the status on the same order page until the return is approved and the refund is processed.

## Reviews

Reviews help other shoppers choose, and they help BeautyComm improve what it sells.

1. Open a delivered order, or the product page of something you bought.
2. Select the number of stars you want to give.
3. Write a few lines about how the product worked for you.
4. Submit the review. It may appear after a quick check by the store team.
