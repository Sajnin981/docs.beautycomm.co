Follow your order from confirmation to delivery. To track an order:

1. Open **My Orders** and click the order you want to track.
2. Click **Track Order**.

   <Screenshot alt="BeautyComm Order Tracking screenshot" label="Capture for Order Tracking" description="Capture: Order details page with Track Order button highlighted. Suggested filename: tracking/01-track-button.png" caption="tracking/01-track-button.png" />

3. Check the timeline for each stage, for example: Order Placed, Packed, Shipped, Out for Delivery, Delivered.

   <Screenshot alt="BeautyComm Order Tracking screenshot" label="Capture for Order Tracking" description="Capture: Tracking timeline. Suggested filename: tracking/02-timeline.png" caption="tracking/02-timeline.png" />

4. If a courier tracking number is shown, use it on the courier's website for live updates.

You also receive notifications when the order status changes.
