## Profile & Settings

Keep your personal details current so orders, invoices and support replies reach you.

1. Select **Account Details** in the Dashboard sidebar.
2. Update your name, phone number, email or profile photo.
3. To change your password, enter the current one first, then the new one twice.
4. Select **Save Changes**.
5. Reload the page to confirm the new details were stored.

## Addresses

Save delivery addresses once and reuse them at checkout instead of typing them each time.

1. Open **Account Details** and find the **Addresses** section.
2. Select **Add New Address**.
3. Fill in the name, phone, city, zone, area and full address, matching the fields used at checkout.
4. Save the address, and mark one as your default if you have several.
5. Use the edit or delete options beside an address when something changes.

## Notifications

Notifications keep you informed about orders, offers and replies without checking each page.

- Open **Notifications** from the profile menu to see your latest alerts, newest first.
- Order updates, coupon offers and support replies each appear as their own entries.
- Select an entry to jump to the related order, coupon or conversation.
- Use the mark-as-read option to clear alerts you have already seen.
