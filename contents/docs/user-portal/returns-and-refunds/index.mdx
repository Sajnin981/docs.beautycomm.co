If something is wrong with your order, you can request a return or refund within the return period. To start a return:

1. Open **My Orders** and select the delivered order.
2. Click **Return / Refund**.

3. Select the items, choose a reason (damaged, wrong item, not as described) and upload photos if requested.

   <Screenshot alt="BeautyComm Returns &amp; Refunds screenshot" label="Capture for Returns &amp; Refunds" description="Capture: Return request form. Suggested filename: returns/02-return-form.png" caption="returns/02-return-form.png" />

4. Choose a refund method and click **Submit Request**.
5. Track the request under **My Returns**. Once approved and the item is received, your refund is processed.

Refund times depend on your payment method. See the Returns & Refund Policy for details.
