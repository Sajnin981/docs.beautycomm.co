The home page is the front door of the BeautyComm store. It brings together promotions, categories and recommended products so visitors can start shopping quickly. To use it:

1. Open the BeautyComm store in your browser.

   <Screenshot alt="BeautyComm Storefront Home Page screenshot" label="Capture for Home Page" description="Capture: Full home page, scrolled to the top, with numbered callouts on each section. Suggested filename: storefront/home/01-overview.png" caption="storefront/home/01-overview.png" />

2. Use the header to search, open the menu, view your account, wishlist and cart.

   <Screenshot alt="BeautyComm Storefront Home Page screenshot" label="Capture for Home Page" description="Capture: Header close-up with search bar, account icon, wishlist and cart labelled. Suggested filename: storefront/home/02-header.png" caption="storefront/home/02-header.png" />

3. Scroll to browse the banner, featured categories, new arrivals, best sellers and current offers.
4. Click any banner, category or product to go straight to it.
5. Use the footer for policies, support links and social media.

   <Screenshot alt="BeautyComm Storefront Home Page screenshot" label="Capture for Home Page" description="Capture: Footer with link groups visible. Suggested filename: storefront/home/03-footer.png" caption="storefront/home/03-footer.png" />

The home page changes with campaigns and offers, so check back often.
