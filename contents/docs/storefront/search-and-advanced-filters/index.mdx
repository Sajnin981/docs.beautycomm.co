Find the right product with search and filters. To use them:

1. Type a product name, brand or concern in the search bar. Suggestions appear as you type.

   <Screenshot alt="BeautyComm Storefront Search &amp; Advanced Filters screenshot" label="Capture for Search &amp; Advanced Filters" description="Capture: Search bar with suggestions dropdown. Suggested filename: storefront/search/01-search-suggestions.png" caption="storefront/search/01-search-suggestions.png" />

2. Press Enter to open the results page.
3. Use the filter panel to narrow by category, brand, price range, skin type, rating and availability.

   <Screenshot alt="BeautyComm Storefront Search &amp; Advanced Filters screenshot" label="Capture for Search &amp; Advanced Filters" description="Capture: Filter panel with several filters selected. Suggested filename: storefront/search/02-filter-panel.png" caption="storefront/search/02-filter-panel.png" />

4. Remove filters one by one with the tags above the results, or click **Clear All**.

   <Screenshot alt="BeautyComm Storefront Search &amp; Advanced Filters screenshot" label="Capture for Search &amp; Advanced Filters" description="Capture: Active filter tags above results. Suggested filename: storefront/search/03-active-filters.png" caption="storefront/search/03-active-filters.png" />
