The shop page lists all products with options to sort and compare. To use it:

1. Click **Shop** in the main menu.

2. Read each product card: image, name, price, discount and rating.

   <Screenshot alt="BeautyComm Storefront Shop &amp; Product Listing screenshot" label="Capture for Shop &amp; Product Listing" description="Capture: A single product card with callouts on each element and the quick actions (wishlist, add to cart). Suggested filename: storefront/listing/02-product-card.png" caption="storefront/listing/02-product-card.png" />

3. Use **Sort By** to change the order, and the grid or list icons to change the layout.
4. Scroll or use the page numbers at the bottom to see more products.
