Short definitions of terms you will meet across BeautyComm guides.

| Term | Meaning |
| --- | --- |
| **SKU** | Stock keeping unit. A unique code that identifies one sellable version of a product. |
| **Variant** | A version of a product, for example a different shade or size. Each variant can have its own SKU and stock. |
| **Attribute** | A property of a product, such as shade, finish or volume. |
| **Catalog** | The full list of products in your shop. |
| **Inventory** | The number of units you have available to sell. |
| **Low stock** | A stock level at or below the point where you should reorder. |
| **Order status** | The stage an order has reached, for example pending, paid or shipped. |
| **Payment status** | Whether an order has been paid, is waiting for payment or was refunded. |
| **Fulfillment** | Preparing and delivering an order to the customer. |
| **Discount** | A price reduction applied to a product or order. |
| **Promotion** | A time-limited offer that may use discounts or codes. |
| **Sales channel** | A place where customers buy from you, such as an online store. |
| **Role** | A set of permissions that decides what a user can see and do. |
| **Integration** | A connection between BeautyComm and another service. |
| **Draft** | An unpublished item, or a documentation page still being verified. |

<Note>Terms in your account may be named slightly differently depending on your BeautyComm version.</Note>
