This documentation is organized for two distinct audiences: BeautyComm client businesses and their shoppers. Choose the side that matches what you are trying to do.

## Start with the right section

- [Getting Started](/docs/getting-started) helps you understand the platform and learn the recommended onboarding path.
- [Business Admin Panel](/docs/admin-panel) is for e-commerce businesses using BeautyComm to manage their store and staff.
- [Shopper Portal](/docs/user-portal) is for customers browsing a store, checking out, and managing their customer account.
- [Shopper Mobile App](/docs/mobile-app) is for customers using a supported mobile shopping app.
- [Common Tasks](/docs/common-tasks) is the best place to follow step-based procedures for everyday work.
- [Troubleshooting](/docs/troubleshooting) is organized around symptoms and common issues.
- [FAQ](/docs/faq) gives short answers to frequent questions.

## How to navigate quickly

1. Use the sidebar to move between major sections.
2. Use the search function when you already know the topic or keyword.
3. Use the page table of contents on the right side of long guides to jump to the relevant section.
4. Move between related pages using the links at the bottom of each article.
5. Use [Common Tasks](/docs/common-tasks) when you need a task-focused instruction set instead of a conceptual overview.

## A practical reading path

- If you are a business client or staff member new to BeautyComm, start with [Welcome to BeautyComm](/docs/getting-started).
- If you are shopping, start with the [Shopper Portal](/docs/user-portal).
- If you need to complete a task, use [Common Tasks](/docs/common-tasks).
- If something does not work as expected, check [Troubleshooting](/docs/troubleshooting) before escalating.
- If you need a short answer, use [FAQ](/docs/faq).

## Notes

- Some pages are written as conceptual guidance and should be read alongside the live product experience.
- Screens, labels, permissions, and workflows can vary by role, business setup, and product version. Shopper options also vary by store.
- When a page references a real feature, confirm the exact behavior in your BeautyComm environment before making operational decisions.
