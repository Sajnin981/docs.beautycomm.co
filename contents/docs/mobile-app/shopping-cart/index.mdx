## Manage Cart

Review and adjust your cart before you pay.

1. Tap the cart icon to open it.
2. Use the minus and plus buttons to change quantities.
3. Tap the remove icon to delete an item.
4. Check the Cart Total, then continue to checkout.

## Coupons

Apply a discount code while your cart is open.

- Tap the coupon field and type or paste your code.
- Tap **Apply** and check that the Discount line changes.
- If the code is rejected, check its expiry date and minimum order amount.
