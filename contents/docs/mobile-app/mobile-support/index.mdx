## Install or Open the App

Confirm that you have the official app for the store and that your device meets its published requirements. Check available storage and install only from the official app-store listing or the store’s website.

## Customer Sign-In Problems

Check that you are signing in to the correct store account, verify your connection, and use the app’s password-recovery process if necessary. Do not send your password or verification code to support.

## Slow Loading or Network Issues

Check that your phone has a stable connection and retry the affected page or shopping step. If possible, compare with the store website. Avoid repeatedly submitting checkout or payment while a request is still processing.

## Update the App

Check for updates using the same official app-store source. Do not install packages from third-party download sites or unsolicited links.

## Contact the Store

When contacting the store, include the time, affected screen, app or device version if known, and the exact error message. For an order issue, include the order reference. Hide personal details in screenshots. Never send passwords, one-time codes, or full payment-card information.
