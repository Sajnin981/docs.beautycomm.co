Request a return if there is a problem with your order. To start:

1. Open **My Orders** and tap the delivered order.
2. Tap **Return / Refund**.

3. Select the items and the reason, and add photos using your camera or gallery if asked.

   <Screenshot width={300} alt="BeautyComm mobile Returns &amp; Refunds screen" label="Phone capture for Returns &amp; Refunds" description="Capture: Return form with photo upload. Suggested filename: mobile/returns/02-form.png" caption="mobile/returns/02-form.png" />

4. Tap **Submit Request**, then follow its progress under **My Returns**.
