The BeautyComm mobile app brings the full shop to your phone. To get started:

1. Open the **Google Play Store** (Android) or the **Apple App Store** (iOS).

   <Screenshot width={300} alt="BeautyComm mobile App Installation &amp; Updates screen" label="Phone capture for App Installation &amp; Updates" description="Capture: Store home screen on the phone. Suggested filename: mobile/install/01-store-home.png" caption="mobile/install/01-store-home.png" />

2. Search for **"BeautyComm"** and tap **Install** (or **Get** on iOS).

   <Screenshot width={300} alt="BeautyComm mobile App Installation &amp; Updates screen" label="Phone capture for App Installation &amp; Updates" description="Capture: Store search result showing the BeautyComm app listing and Install button. Suggested filename: mobile/install/02-store-listing.png" caption="mobile/install/02-store-listing.png" />

3. If your device cannot use the store, download the app file from [website download link] and allow installation from this source when asked.
4. Open the app and allow the permissions it asks for, such as notifications, camera (for scanning product codes) and location [if used].

   <Screenshot width={300} alt="BeautyComm mobile App Installation &amp; Updates screen" label="Phone capture for App Installation &amp; Updates" description="Capture: Permission prompt screen. Suggested filename: mobile/install/03-permissions.png" caption="mobile/install/03-permissions.png" />

5. To update, open the store, search for BeautyComm and tap **Update**. You can also turn on automatic updates in your store settings.

   <Screenshot width={300} alt="BeautyComm mobile App Installation &amp; Updates screen" label="Phone capture for App Installation &amp; Updates" description="Capture: Store listing with the Update button. Suggested filename: mobile/install/04-update.png" caption="mobile/install/04-update.png" />

After installation, you can start browsing products, placing orders, tracking deliveries and managing your account.
