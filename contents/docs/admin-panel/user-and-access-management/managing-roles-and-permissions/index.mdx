Roles decide what each user can do.

## Purpose

Explain how to assign and review roles.

## Who can use it

Administrators and other users whose role includes administrative access.

## Where to find it

Open the users or access area of the Admin Panel.

## Before you begin

- Administrator access.

## Steps

1. Open user management.
2. Select a user.

<Screenshot step={2} alt="User list" label="User list" />

3. Choose a role.
4. Review its permissions.
5. Save.

## Expected result

The user has the access that the role grants.

## Notes

- Give people the least access they need.
- Review roles regularly.

## Common problems

| Problem | What to try |
| --- | --- |
| User cannot see a menu | Check their role permissions. |
