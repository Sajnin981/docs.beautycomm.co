## Available Integrations

Only integrations listed or approved for your BeautyComm environment should be configured. Availability can differ across organizations and plans.

## Connecting Supported Services

Connect services using the organization’s approved setup process. Confirm account ownership and required permissions before starting, and never place credentials in documentation or support requests.

## Integration Configuration

Configuration may include service-specific options that affect data exchange or behavior. Record approved changes and verify them in the appropriate environment.

## Integration Status

Use the status information available in your workspace to determine whether a connection appears active or needs review. A displayed status may not alone confirm that all data is current.

## Integration Troubleshooting

For a connection or sync issue, note the integration name, approximate time, affected workflow, and any error message. Check configuration and service availability through approved channels before escalating.
