## Understanding Access Levels

Access levels determine which data and actions are available to a user. Assign only the access needed for the role, and review it when responsibilities change.

## Managing Authorized Users

Maintain an accurate list of authorized users and follow the organization’s approval and offboarding processes. Remove access promptly when it is no longer required.

## Account Security

Use unique credentials, complete required verification, and sign out of shared devices. Report suspicious access through the organization’s approved security channel.

## Credential and Secret Handling

Never share passwords, verification codes, API keys, or other secrets in documentation, screenshots, or ordinary support requests. Use approved secure channels and secret-management processes.

## Access-Related Troubleshooting

Check the correct environment, account status, and assigned role first. If access still appears wrong, report the affected workflow and user context without including credentials or secrets.
